  변경 요약                                                                     
  ┌──────────────────┬─────────────────┬───────────────────────┐                
  │       항목       │      이전       │         이후          │                
  ├──────────────────┼─────────────────┼───────────────────────┤                
  │ backward_fn 타입 │ Box<dyn Fn()>   │ Option<Box<dyn Fn()>> │                
  ├──────────────────┼─────────────────┼───────────────────────┤                
  │ 초기화           │ Box::new(|| {}) │ None                  │                
  ├──────────────────┼─────────────────┼───────────────────────┤                
  │ 호출 방식        │ 직접 호출       │ take() 후 호출        │                
  └──────────────────┴─────────────────┴───────────────────────┘                
  피드백 평가                                                                   
                                                                                
  맞는 부분:                                                                    
  - take()로 클로저를 꺼내서 borrow scope를 분리하는 것은 좋은 패턴             
  - Option으로 바꾸는 것이 더 안전                                              
                                                                                
  불필요한 부분:                                                                
  - 피드백에서 f() 호출 후 backward_fn = Some(f)로 복원하라고 했는데, backward
   한 번만 호출되므로 복원이 불필요함                                           
  - 오히려 take()로 소유권을 가져오면 클로저가 일찍 해제되어 메모리 효율적      
                                                                                
  추가 개선:                                                                    
  - leaf 노드는 backward_fn이 없으므로 Some(Box::new(|| {}))대신 None으로 초기
   (메모리 절약)                                                                
                                                                                
  왜 이게 더 안전한가                                                           
                                                                                
  // 이전: borrow가 클로저 실행 중에도 유지됨                                   
  (node.0.borrow().backward_fn)();  // ← borrow 유지 상태에서 f() 실행          
                                                                                
  // 이후: borrow 해제 후 클로저 실행                                           
  let backward = {                                                              
      let mut inner = node.0.borrow_mut();                                      
      inner.backward_fn.take()  // 여기서 클로저 소유권 이동                    
  };  // ← 여기서 borrow_mut 해제                                               
                                                                                
  if let Some(f) = backward {                                                   
      f();  // ← borrow 없는 상태에서 실행                                      
  }                                                                             
                                                                                
  클로저 실행 중 어떤 노드든 자유롭게 borrow_mut() 가능 → RefCell panic 위험
